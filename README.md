# AppleBooks2Floder

简体中文 · [English](README.en.md)

一个供个人使用的 macOS 应用。把 Apple Books 中已下载、无 DRM 的 PDF 和 EPUB 导出到坚果云或其他网盘的同步文件夹，再在 Android、平板或支持相应格式的电子书阅读器上打开。

## 使用方法

1. 解压 `AppleBooks2Floder-macOS.zip`，把 `AppleBooks2Floder.app` 移到「应用程序」并打开。应用支持 macOS 14 及以上，安装包包含 Apple 芯片和 Intel 版本。
2. 在 Mac 的「图书」里下载要导出的书。AppleBooks2Floder 会自动识别资料库和标准的本地、iCloud 图书原件目录。若 macOS 提示访问其他应用数据，请允许访问。
3. 点击「选择文件夹」，选择已配置的网盘同步目录或其中的子目录。坚果云云桥用户可从访达侧栏「位置」进入坚果云。也可以选择普通本地文件夹。
4. 在「导出范围」选择全部或前面的书。点击「立即导出」，或开启「自动同步」并选择同步频率。关闭窗口后应用仍在菜单栏运行，可从菜单栏暂停自动同步或立即导出。
5. 等网盘客户端完成上传后，在 Android 或其他设备上打开同一目录，用阅读应用打开或导入 PDF／EPUB。电子书阅读器需要能访问该目录，或通过自己的传书方式导入文件。

参考 [Apple Books 下载指南](https://support.apple.com/en-gb/guide/books/ibks5f526382/mac)、[macOS 文件夹授权说明](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox)和[坚果云 Mac 云桥说明](https://help.jianguoyun.com/?p=6334)。

## 界面语言

支持简体中文和英语。应用默认跟随 macOS 的语言偏好。若要单独切换，在「系统设置 → 通用 → 语言与地区 → 应用程序」中添加 AppleBooks2Floder，选择语言，再退出并重新打开应用。语言偏好中没有匹配项时使用英语。[Apple 的应用语言设置说明](https://support.apple.com/zh-cn/guide/mac-help/mh26684/mac)

## 文件夹权限

应用启用 macOS App Sandbox，图书读取权限限定在 Apple Books 资料库、iCloud 图书和旧版图书的标准目录。通过系统选择器选定的目标文件夹使用读写授权。书目数据库和可能存在的写入日志短暂复制到应用自己的临时目录后读取。

如果 macOS 拒绝读取且没有弹出系统提示，点击「授权图书资料库」或导出结果中相应的授权按钮。如果系统面板停在「文稿」等其他位置，点击「复制图书路径」。按 **⌘ Command + ⇧ Shift + G** 打开「前往文件夹」，粘贴路径并回车。到达图书目录后点击「授权」，应用会保存只读授权并自动重试。

升级后会尝试继续使用已保存的目标文件夹。如果目标授权已失效，请重新选择目标。若旧版曾获完全磁盘访问权限，可在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中关闭 AppleBooks2Floder。

## 导出范围和同步频率

- **全部**是默认范围。选择**前面的**后，可输入 1–2,000 本并点击「应用」。默认按「图书 → 全部」当前顺序选取，也可指定最近、书名、作者或手动顺序。未下载或受保护的书占用所选名额，因此实际导出数量可能少于设定值。缩小范围会保留之前导出的文件。
- 自动同步可选 **1、5、15、30 或 60 分钟**，默认 **15 分钟**。频率控制 Mac 检查和导出的间隔，网盘上传时间由网盘客户端决定。关闭自动同步后可继续使用「立即导出」。

## 导出规则

- PDF 和已打包的 EPUB 按原文件复制。Apple Books 以文件夹形式保存的 EPUB 会重新打包为单个 `.epub` 文件。
- 应用只读访问 Apple Books 本地书库。导出是单向的，范围是书籍文件。阅读进度、笔记、书签和合集留在 Apple Books。
- 重复检查会跳过已有的相同文件。同名但内容不同的书会带后缀另存。删除 Apple Books 里的书会保留已导出的文件。移走导出副本后，下一轮可以重新导出。
- 受 DRM 或加密保护的书会跳过。原件尚在云端时，先在「图书」中下载，再重试。「导出结果」可查看待下载、跳过和失败的条目。
- 网盘客户端负责上传和其他设备的下载。应用本身在本地运行，无网盘账号配置。应用显示的是本机导出结果，云端传输进度在网盘客户端查看。
- 目标文件夹授权、导出范围、排序、频率和导出缓存保存在应用自己的沙盒内。Apple Books 采用内部书库格式。如果无法识别「全部」排序，可手动选用与「图书」相同的排序。

## 从源码构建

本目录是独立的 Swift 包。使用 Xcode 15 或更新版本，在本目录运行以下命令。

```sh
swift test
./scripts/build-app.sh
```

安装包生成在 `dist/AppleBooks2Floder-macOS.zip`。脚本默认使用本地临时签名，也可通过 `APPLEBOOKS_SIGN_IDENTITY` 指定签名身份。跨签名身份升级后，macOS 可能要求重新选择目标文件夹。
